# Agora RTC Token Server for ESTATY

This is a development token server for the ESTATY React Native app. It generates Agora RTC tokens for authenticated call participants.

## Purpose

- Generates RTC tokens server-side using App ID + App Certificate
- Never exposes the App Certificate to the React Native app
- Each participant gets their own token for the same channel with their own numeric UID
- Uses `RtcRole.PUBLISHER` for both buyer and seller (1-to-1 calls)

## Setup

1. **Install dependencies:**
   ```bash
   cd token-server
   npm install
   ```

2. **Configure environment variables:**
   ```bash
   cp .env.example .env
   # Edit .env with your Agora credentials
   ```

3. **Get Agora credentials:**
   - Go to [Agora Console](https://console.agora.io/)
   - Select your project
   - Copy **App ID** and **App Certificate**
   - **Important**: Enable App Certificate for your project

4. **Start the server:**
   ```bash
   npm start
   # or
   node server.js
   ```

   Server runs on `http://0.0.0.0:3001`

## API Endpoints

### POST /token

Generate an RTC token for a channel and numeric UID.

**Request:**
```json
{
  "channelName": "estaty_call_ch_123_456_1700000000000",
  "uid": 123456789
}
```

**Response:**
```json
{
  "token": "007eJxTYDhN...",
  "expiresIn": 3600,
  "expireTimestamp": 1700003600
}
```

**Errors:**
- `400` - Invalid channelName or uid
- `500` - Server configuration error or token generation failure

### GET /health

Health check endpoint.

**Response:**
```json
{
  "status": "ok",
  "service": "agora-token-server"
}
```

## React Native Integration

The app requests tokens from this server before joining Agora channels:

1. Buyer initiates call → generates channel name + numeric UID
2. Buyer requests token: `POST /token` with channelName + UID
3. Buyer joins Agora with token
4. Seller accepts call → uses same channelName, generates own numeric UID
5. Seller requests token: `POST /token` with same channelName + their UID
6. Seller joins same Agora channel with their token

## Network Configuration for Physical Devices

**Important:** The server listens on `0.0.0.0` so devices on the same Wi-Fi can reach it.

1. Find your Mac's LAN IP:
   ```bash
   ifconfig | grep "inet " | grep -v 127.0.0.1
   # Example output: inet 192.168.1.100 netmask 0xffffff00 broadcast 192.168.1.255
   ```

2. Configure the React Native app to use `http://192.168.1.100:3001` (NOT `localhost`)

3. Both Android devices must be on the same Wi-Fi network as the Mac

## Security Notes

⚠️ **DEVELOPMENT ONLY** - This server has NO authentication or authorization.

For production deployment:
- Add HTTPS (reverse proxy with nginx + certbot)
- Add user authentication (verify user owns the call)
- Add rate limiting
- Validate channelName matches active call in Firebase
- Use shorter token expiration (e.g., 1 hour)
- Consider token renewal endpoint (`/renew-token`)

## Token Lifetime

- Default: 1 hour (3600 seconds)
- Maximum allowed by Agora: 24 hours (86400 seconds)
- Token renewal: Client should handle `onTokenPrivilegeWillExpire` callback (fires 30s before expiry)

## Channel Names & UIDs

- Channel names: Dynamic, generated by `callSignaling.js` as `estaty_call_ch_{callerId}_{receiverId}_{timestamp}`
- UIDs: Numeric, derived from user ID via stable hash function in `agoraRTCService.js`
- Both participants use the SAME channel name but DIFFERENT UIDs
- Each participant must request token with their own UID

## Testing on Two Android Devices

1. Start token server: `cd token-server && npm start`
2. Note Mac LAN IP (e.g., `192.168.1.100`)
3. Update React Native app token server URL to `http://192.168.1.100:3001`
4. Build and install app on both devices (`npm run android`)
5. Sign in as different users (buyer and seller)
6. Buyer initiates call to seller
7. Both devices should join the call with valid tokens

## Troubleshooting

| Issue | Solution |
|-------|----------|
| "App ID + Token required" | Enable App Certificate in Agora Console |
| Token generation fails | Check AGORA_APP_ID and AGORA_APP_CERTIFICATE in .env |
| Device can't reach server | Use Mac's LAN IP, not localhost; check firewall |
| Call drops after 1 hour | Implement token renewal via `onTokenPrivilegeWillExpire` |
| "Invalid uid" | UID must be integer 0 to 4294967295 |
